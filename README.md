# Miner-Safety-Sensor-Suite
The idea of this device was relatively simple. If I were descending into a mineshaft, what would be the sort of gear and tools I might need to keep abreast of the hazards of the mine. This project aims to provide a very simple version of that.

Now this was my very first truly complex(for me) project with multiple sensors working together. Hopefully, I can add more sensors to it and improve it someday.
